## Android'de yükleme

Bağlantıyı Android telefonda Chrome ile açın. Sayfadaki **Uygulamayı yükle** düğmesine dokunun; düğme görünmezse Chrome menüsünden **Uygulamayı yükle** veya **Ana ekrana ekle** seçeneğini kullanın.


## İl bazlı liste ve istatistikler

İl/ilçe/kurum araması korunur. İl seçildiğinde, uygulamanın mevcut kayıtları il bazında sağ panelde gösterilir; sayfanın altındaki 81 il listesi de aynı kurum verisini kullanır.

3 Eylül 2026 tarihli ulusal gösterge tablosu tarihsel veri olarak ayrı sunulur ve CTE PDF/CİSST kaynaklarına bağlanır. Bu göstergeler uygulamanın il kayıtlarıyla birleştirilmez.
